# AI Tools Assignment - Theoretical Analysis

## Part 1: Theoretical Understanding

### 1. Short Answer Questions

**Q1: Explain how AI-driven code generation tools (e.g., GitHub Copilot) reduce development time. What are their limitations?**

**Answer:**
AI code generation tools reduce development time by:
- Providing instant code suggestions and auto-completion
- Generating boilerplate code and common patterns
- Offering context-aware recommendations based on existing code
- Reducing syntax errors and debugging time

**Limitations:**
- May suggest insecure or inefficient code
- Limited understanding of business logic requirements
- Potential copyright issues with generated code
- Can create over-reliance reducing developer learning

**Q2: Compare supervised and unsupervised learning in the context of automated bug detection.**

**Answer:**
**Supervised Learning:**
- Uses labeled data (buggy/non-buggy code)
- Better for known bug patterns
- Requires extensive labeled datasets

**Unsupervised Learning:**
- Identifies patterns without labels
- Can discover novel bug types
- Works with raw code data

**Q3: Why is bias mitigation critical when using AI for user experience personalization?**

**Answer:**
Bias mitigation is crucial because:
- Prevents exclusion of user groups from optimal experiences
- Avoids reinforcing societal stereotypes
- Ensures fair treatment across demographics
- Maintains user trust and engagement
